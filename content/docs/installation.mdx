Requires Rust stable with Cargo installed.

## Install

To install the binary, run:

```sh
cargo install --path crates/fls
```

To run from source without installing:

```sh
cargo run -p fls -- lsp
```

To confirm the install, run:

```sh
fls --version
```

## Connect your editor

The server speaks JSON-RPC over stdio. Point any generic LSP client at the `lsp` subcommand:

- Command: `fls lsp`
- Transport: `stdio`
- Language id: `solidity` for `.sol` files

No editor-specific plugin is needed. If your editor asks for a language id or file pattern, use `solidity` and `*.sol`.

## Verify

1. Open a folder containing a `.sol` file.
2. Open the file in your editor.
3. Break something on purpose, for example delete a semicolon.
4. A diagnostic should appear within ~200 ms (the default debounce delay).

If nothing happens, run `fls lsp` in a terminal. Startup and config problems print as `fls: ...` warnings on stderr.

## Lint without an editor

To lint files from the terminal without an editor, use the `check` subcommand:

```sh
fls check
```

See [CLI reference](/docs/cli) for flags, exit codes, and JSON output.
