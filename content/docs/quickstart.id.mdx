Panduan ini menganggap [Instalasi](/docs/installation) sudah selesai dan editor mengarah ke `forgels` lewat stdio.

<Steps>
<Step>
### Buat file uji

Simpan ini sebagai `Counter.sol` di folder kosong:

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract Counter {
    uint256 public total;

    function add(uint256 amount) public {
        total += amount;
    }
}
```

Buka folder di editor, lalu buka `Counter.sol`.
</Step>
<Step>
### Cek diagnostics

Hapus titik koma setelah `total += amount` dan tunggu sebentar. Diagnostic error akan muncul di baris itu. Batalkan edit dan pastikan diagnostic hilang.

Diagnostics memakai debounce (bawaan 200 ms) dan dibersihkan saat file ditutup.
</Step>
<Step>
### Cek hover dan goto-definition

- Arahkan kursor (hover) ke `total` di dalam `add`. Info tipe dan deklarasi akan tampil.
- Letakkan kursor di `total` lalu picu goto-definition. Kursor akan lompat ke deklarasi state variable.
</Step>
<Step>
### Cek completion

Ketik `total.` atau mulai ketik identifier yang dikenal lalu picu completion. Member contract, simbol dalam scope, dan simbol import (untuk proyek multi-file) akan disarankan.
</Step>
<Step>
### Coba proyek multi-file

Buat file kedua `Wrapper.sol` yang mengimpor file pertama:

```solidity
import "./Counter.sol";

contract Wrapper {
    Counter public counter;
}
```

Hover dan goto-definition pada `Counter` terpecahkan lintas file. ForgeLS membangun ulang indeks proyek saat file dibuka dan diubah, serta me-refresh file dependen saat target import diedit.
</Step>
</Steps>
